# HiEnWrite VGG19 vs ViT-B16

Eksperimen Tugas Akhir untuk membandingkan VGG19 dan ViT-B16 dalam prediksi lima skor kontinu Big Five Personality (OCEAN) menggunakan dataset HiEnWrite.

## Models
- VGG19 (CNN / local representation)
- ViT-B16 (Vision Transformer / global representation)

## Dataset
HiEnWrite: Hindi-English Bilingual Dataset for Big Five Personality Detection.

## Method
- Writer-level train/test split
- 10-Fold Cross-Validation
- Continuous OCEAN regression
- MSE
- RMSE
- PCC

## Environment
- Python
- PyTorch
- GPU
